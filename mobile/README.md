# AniKeeper

Protótipo mobile para Android feito com React Native, Expo e Expo Router.

## Começar

```bash
npm install
npm run android
```

Também é possível iniciar o Expo com `npm start` e abrir o projeto pelo Expo Go ou emulador Android.

## Telas

- Login e cadastro em rotas públicas.
- Coleção com listas de animes assistindo, quero ver e concluídos.
- Perfil com alternância entre tema claro e escuro.

As listas e estatísticas são dados de demonstração. Login, cadastro e sessão são locais, sem servidor ou validação de credenciais; o tema escolhido fica salvo no dispositivo.
